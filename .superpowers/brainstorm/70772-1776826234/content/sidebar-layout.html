方案 A — 固定宽度侧边栏

固定 200px 左栏，顶部有"文件"/"目录"两个 Tab 切换。与现有 HSplitView 并列，整体布局为三栏。

优点

  • 布局稳定，始终可见
  • 实现简单

缺点

  • 窄屏下挤占编辑区

方案 B — 图标栏 + 浮层展开

默认只显示窄图标栏（28px），点击图标展开为浮层面板，不挤占编辑区。类似 VS Code 侧边栏。

优点

  • 编辑区不受挤压
  • 体验现代

缺点

  • 实现较复杂
  • 浮层遮挡内容

方案 C — 可拖拽调宽侧边栏（推荐）

通过 HSplitView 统一管理三栏（侧边栏 | 编辑 | 预览），侧边栏可拖拽调宽、可折叠为 0。Cmd+\\ 切换显示。与现有架构最契合。

优点

  • 原生 macOS 体验
  • 复用现有 HSplitView
  • 可完全收起

缺点

  • 三栏同时存在时较窄
